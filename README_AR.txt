Alpha Leader · سلسلة فيديو تفاعلية (عربي / إنجليزي)

جوه الفولدر:
- index.html : الصفحة (زرار فوق يبدّل بين العربي والإنجليزي، والفيديو بيكمّل من نفس الحتة)
- media/     : الفيديوهات (نسخة عربي AR ونسخة إنجليزي EN لكل فيديو)
- fonts/     : الخطوط

تجربة سريعة على الكمبيوتر:
افتح index.html بـ Chrome أو Edge.

الرفع على GitHub Pages:
1. اعمل Repository جديد (Public).
2. Add file > Upload files: ارفع index.html و README_AR.txt وفولدر fonts في Commit واحد.
3. ارفع فولدر media، وكل فيديو في Commit لوحده لو الرفع رفض (كل فيديو حوالي 14 ميجا).
4. Settings > Pages > Branch: main > Save. اللينك بيظهر بعد دقيقة أو اتنين.
   (index.html لازم يبقى في أول الريبو، مش جوه فولدر.)
